# JavaScript inlined in `tree.html`

| Library | Version | Licence | Files |
|---|---|---|---|
| [family-chart](https://github.com/donatso/family-chart) | see `family-chart/VERSION` | MIT (`family-chart/LICENSE.txt`) | `family-chart.min.js`, `family-chart.css` |
| [d3](https://d3js.org) | see `d3/VERSION` | ISC (`d3/LICENSE`) | `d3.min.js` |

They are copied from the npm packages (`npm pack family-chart@<version> d3@<version>`), unchanged, and
inlined into each `tree.html`, which therefore opens offline.
