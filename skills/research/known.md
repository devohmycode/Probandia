# Before announcing something new

Before writing that a finding is new, or that "X remains unknown", "the file
has no Y", "no source says Z" (each is a claim about what is known):
- Check `known` with every proper name and title it involves, and
  grep the report's text (`report/`) for them, never reading it whole.
- For an event, search in this order: the place, the date written out in
  words, every proper name of the scene, then the object sought.
- A name already there does not answer the question. Ask what this source
  adds: compare field by field (shelf mark, date, people, physical form). A
  finding already known goes in as a precision, saying which.
- For a corpus already on disk, say what of it has been read and what has not.
